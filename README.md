## What I learned
Terminal is kind of convenient and inconvenient in its own way when it comes to writing code and pushing to GitHub.
Pushing is a tad inconvenient, since I have to run specific commands and the setup process was also more involved than using the GitHub website,
however, using the terminal that's already on the computer rather than installing GitHub Desktop to upload massive amounts of files is definitely more
convenient, especially after writing code write in the same window.
